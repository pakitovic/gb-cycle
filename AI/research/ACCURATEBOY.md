# accurateboy

## Why keep this reference
- Very useful for PPU, pixel fetch, and FIFO-oriented study
- Good reference when validating LCD pipeline ideas

- Architecture ideas
- Subsystem-specific implementation patterns

- pixel fetch / FIFO behavior
- dot-timing-sensitive rendering behavior
