# Danger Boy

Repository: https://github.com/austinthresher/dangerboy

## Why keep this reference
- Useful DMG timing-oriented implementation reference
- Good for studying CPU/bus structure with a cycle-accurate mindset

## What to consult it for
- Architecture ideas
- Subsystem-specific implementation patterns
- Behavioral cross-checks when documentation is ambiguous

## Cautions

## Typical subsystems to inspect
- CPU / bus
- PPU / LCD
- Timing-sensitive behavior
